# 架构说明

## 前端

前端使用 Next.js App Router、React、TypeScript、Tailwind CSS 与 shadcn/ui 风格组件。语言路由始终带前缀：`/zh-CN` 与 `/en-US`。

首页右上角提供后台入口和语言切换下拉。语言切换保留当前路径结构，例如 `/zh-CN/admin` 切换为 `/en-US/admin`。

首页主体是左右结构工作台：左侧为图标 Logo、新消息、剧本入口、素材入口、消息搜索和按时间分组的会话列表，右侧为剧本选择、剧本管理、素材管理或 AI 聊天窗口。左侧支持收起；收起后不显示独立展开按钮，鼠标悬浮或键盘聚焦 Logo 时可展开。点击“新消息”回到剧本选择，剧本选择页默认展示我的剧本，使用每页 3 列 2 行的紧凑卡片，卡片点击即创建会话；超过 6 个剧本时才在卡片下方显示左右切换按钮和页数，不足一页或最后一页数量不足时卡片居中显示。点击“剧本”默认进入“我的剧本”，卡片会显示来源标记，右上角可查看社区剧本。社区剧本页沿用参考 GPT 探索页的剧本管理页，包含搜索、sticky 分类导航、按分类分区内容和剧本详情弹窗；分类高亮会通过滚动观察跟随当前内容变化。点击“素材”默认进入“我的素材”，素材管理页沿用相同的左侧入口和社区切换结构，但采用更偏图文画廊的卡片、固定内容风格分区和素材详情弹窗；卡片预览图点击进入详情，详情顶部设定板按 16:9 完整展示且不裁切，并支持点击放大查看；顶部风格包括写实、玄幻、科幻、悬疑、赛博、古风和末世，假面、地图、物品、生物作为类型标签显示在卡片和详情里；其中“假面”只抽离人物外观、性格、说话方式和动作习惯，不包含背景故事、身世经历或世界关系。“创建”按钮会先弹出类型选择气泡，选择假面会打开新建假面表单，桌面端表单左侧填写名称、内容风格、假面介绍、身体信息、身体颜色配置、语音特征和性格特征；身体信息字段可直接输入，外观项通过自定义建议浮层辅助选择。右侧分为 AI 辅助对话和 16:9 横版角色设定板；AI 辅助调用默认 LLM 返回结构化 patch 并自动写入表单，设定板可本地上传预览或调用默认图片模型生成，生成按钮左侧提供绘制风格选择并写入生成提示词，保存时上传到 R2。保存假面会创建“我的素材”并写入 `StoryMaterial.metadata`，`previewUrl` 使用设定板 URL；自建假面详情显示“分享到社区”开关、编辑和删除入口，开关打开后该素材进入社区素材列表，关闭后仅保留在我的素材；编辑复用假面表单并更新同一条素材，删除会永久移除素材主记录并由级联关系清理库条目；地图、物品、生物仍为占位提示。社区素材支持加入我的素材，已加入状态会在卡片和详情里同步显示。聊天窗口采用居中消息流与底部多行输入框，输入框不显示剧本名称，并支持 `Enter` 发送、`Shift + Enter` 换行。会话页左上角统一显示当前剧本名称，点击后打开气泡操作列表，目前支持删除当前会话；右上角按上行/下行显示当前会话累计 AI token 消耗，服务商未返回 usage 时使用估算并标注。

剧本管理页不渲染右侧通用头部，避免与探索页自身导航重复；“我的剧本”右上角保留“+ 创建”占位按钮和“查看社区剧本”按钮，社区剧本页右上角显示“返回我的剧本”。搜索和分类栏在剧本页滚动容器内吸顶到最上方。点击剧本卡片打开详情弹窗，遮罩使用与其他弹窗一致的半透明背景和轻微模糊。当前版本暂不实现社区剧本加入操作，只在社区页对已加入我的剧本库的条目显示“已加入”状态。

首页右上角提供设置按钮。设置使用约为原宽度 2/3 的紧凑分栏弹窗：左侧为通用、账号、外观、AI 供应商、LLM 模型、向量模型、图片模型、关于等功能项。通用页使用紧凑行式布局，展示语言切换、前往总站、“显示思考内容”开关和退出登录；总站按钮会在新页面打开 `https://zrg.zrbyhelp.com/`，思考内容开关默认关闭，开启后会把供应商返回的 reasoning 内容展示给用户。账号页单独管理头像、显示名称和密码。头像和名称位于侧栏左下角，替代原数据库连接和默认 LLM 状态；头像从账号设置上传到 Cloudflare R2，支持 GIF/PNG/JPG/WebP，单个文件最大 5MB，前端会在提交前校验格式和大小。未配置公开域名时通过应用代理读取 R2 私有对象。显示名称修改后防抖自动保存；修改密码通过独立弹窗完成。排版密度会写入根字号、行高和密度变量，让 rem 尺寸的全局界面一起变化。AI 配置管理以扁平列表为主，新增或编辑时通过按钮打开弹窗填写，不常驻展示空表单，也避免大框套小框。关于页签展示软件名称、作者、协议、联系方式、GitHub 仓库和 Star 请求，不展示后台入口。AI 配置直接落库并按当前登录账号隔离，供应商 API Key 只支持重填或清空，前端不返回明文；模型表单选择供应商后会通过服务端动作拉取 OpenAI-compatible `/models` 列表，再按 LLM、向量模型与图片模型场景做基础筛选。LLM、向量和图片模型列表行提供快捷默认图标，可直接把启用且供应商可用的模型设为默认。LLM 上下文窗口不作为用户配置项，避免和供应商模型默认上下文策略冲突。

## 后台框架

后台路由为 `/zh-CN/admin` 与 `/en-US/admin`。后台需要管理员角色；未登录访问会跳转到对应语言的登录页，普通用户登录后会看到无权限提示。管理员账号由 `ADMIN_ACCOUNT` 与 `ADMIN_PASSWORD` 环境变量自动确保。

## AI 边界

Vercel AI SDK 仅负责前端流媒体对话展示。后端模型调用使用 `openai` SDK 或 LangChain 适配 OpenAI-compatible 服务。LangGraph、LangChain 与 LangChain Splitter 负责工作流编排、链式处理和文本切分。

所有真实 AI 访问必须进入 Langfuse 观测。Next.js 服务端启动时通过 `src/instrumentation.ts` 注册 Langfuse OpenTelemetry 导出；OpenAI SDK 调用统一使用 `@langfuse/openai` 包装，LangChain 与 LangGraph 调用统一使用 `@langfuse/langchain` callback。非测试环境缺少 `LANGFUSE_PUBLIC_KEY` 或 `LANGFUSE_SECRET_KEY` 时，聊天回复、假面 AI 辅助、图片生成和供应商 `/models` 拉取都会直接报 `missing-langfuse-config`，不继续访问模型服务。

首页聊天回复通过本地 `POST /api/conversations/[conversationId]/stream` 接口返回 NDJSON 事件：`delta` 事件用于实时追加助手文本，`done` 事件返回已持久化的完整会话，前端再用数据库状态替换乐观消息。服务端调用默认 LLM 时会默认携带内部思考参数，并在系统提示中按用户偏好处理思考内容：默认要求模型不要输出私密推理；当用户开启“显示思考内容”后，若供应商在 `reasoning_content` 等字段返回 reasoning，流式与非流式回复都会把它标记为可见思考内容并保存到会话消息中。如果兼容供应商拒绝 `enable_thinking`、`reasoning_effort` 或 usage 流式参数，会自动重试为普通流式调用。

## 数据与任务

MySQL 由 Prisma 管理。首页工作台使用 `AppUser`、`AuthSession`、`StoryScript`、`StoryScriptLibraryEntry`、`StoryMaterial`、`StoryMaterialLibraryEntry`、`Conversation`、`ChatMessage` 持久化用户、会话 cookie、社区剧本目录、我的剧本库、社区素材目录、我的素材库、会话和消息；`AppUser` 保存账号、密码哈希、角色、显示名称、头像地址和 `showAiThinking` 偏好，思考内容默认关闭。头像文件存储在 Cloudflare R2，数据库保存可访问 URL。假面设定板允许 PNG/JPG/WebP 且最大 10MB，Next Server Action 请求体上限设置为 12MB，给保存时上传留出 multipart 余量。使用 `AiProvider`、`LlmModel`、`VectorModel`、`ImageModel` 管理 OpenAI-compatible 供应商、聊天模型、向量模型和图片模型，其中 `AiProvider` 归属到具体 `AppUser`，模型通过供应商继承用户归属。当前版本开放账号密码注册，密码使用 `scrypt` 哈希，登录后写入 `httpOnly` 的 `nwt_session` cookie；`StoryScript` 作为社区目录，`StoryScriptLibraryEntry` 记录我的剧本来源，来源包括自己创建和社区添加。`StoryMaterial` 作为独立素材目录，`category` 保存素材类型，`style` 保存内容风格，`metadata` 保存假面等素材的结构化草稿并随工作台数据回传，`communityVisible` 控制素材是否出现在社区素材列表；`StoryMaterialLibraryEntry` 记录我的素材来源，来源同样包括自己创建和社区添加；编辑、分享或删除自建素材都会校验当前用户的 `SELF_CREATED` 条目，分享开关只更新同一条 `StoryMaterial.communityVisible`，删除自建素材会删除素材主记录并依赖 `onDelete: Cascade` 清理库条目；内置素材会在首页数据读取时自动确保存在并保持 `communityVisible=true`，默认示例会自动加入每个登录用户的素材库，`default-local` 仅用于未登录只读浏览兼容。AI 配置用户化迁移会把已有全局供应商和模型转移到账号 `q19946502`；如果该账号还没有密码，首次注册同名账号时会补写密码并保留迁移过来的配置。

Qdrant 用于向量检索，Neo4j 用于世界观图谱，BullMQ + Redis 用于 AI 分析、向量化、图谱构建等后台任务。

## 首页 AI 回复边界

首页发送消息后会调用当前会话所属用户默认启用的 LLM 模型生成回复。默认模型来自该账号设置弹窗中的 LLM 模型管理；如果当前账号没有启用的默认模型，聊天区会提示用户前往右上角“体验设置”配置 LLM，不再用 `.env` 回退模型代替用户配置。`.env` 中的 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL` 仅作为没有用户上下文的内部兜底配置。如果默认供应商缺少 API Key、密钥无法解密或模型调用失败，服务端会返回错误，不写入模拟助手消息。

前端发送消息时会先做乐观展示，并显示“正在思考并整理剧情”状态；收到流式 `delta` 后实时显示助手文本，服务端完成持久化后再使用最终会话与消息替换本地状态。前端时间统一使用相对与日期组合格式：60 分钟内显示“几分钟前”，今天显示 `HH:mm`，昨天显示“昨天 HH:mm”，更早显示日期和时间；英文界面使用英文等价文案。

向量模型和图片模型本次先完成配置、启停和默认项管理；后续 Qdrant 写入、LangChain Splitter 任务和语义检索会统一读取当前账号的默认向量模型，后续封面、场景图、角色图生成会读取当前账号的默认图片模型。
