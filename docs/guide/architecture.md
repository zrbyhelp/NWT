# 架构说明

## 前端

前端使用 Next.js App Router、React、TypeScript、Tailwind CSS 与 shadcn/ui 风格组件。语言路由始终带前缀：`/zh-CN` 与 `/en-US`。

首页右上角提供“体验设置”入口。语言切换放在设置的通用分类中，并保留当前路径结构，例如 `/zh-CN` 切换为 `/en-US`。

## 代码模块拆分

公开导入路径保持稳定：`@/components/home-workspace`、`@/components/ai-config-manager`、`@/lib/home-workspace`、`@/lib/ai/image-runtime` 和 `@/lib/material-transfer` 仍作为外部调用入口。入口文件只做 re-export 或流程编排，具体实现按目录拆分，避免把工作台、AI 配置、图片运行时和素材导入导出继续堆在单一文件内。

前端工作台实现位于 `src/components/home-workspace/`，按草稿工具、流式请求、列表工具、表单字段、素材详情、假面弹窗、物品弹窗、场景弹窗和全景/模型预览拆分。AI 配置管理位于 `src/components/ai-config-manager/`，拆分为默认表单值、类型、通用字段、布局、列表行和错误提示工具。服务端工作台位于 `src/lib/home-workspace/`，当前拆出类型和默认数据，旧入口保持 `server-only` barrel。图片运行时位于 `src/lib/ai/image-runtime/`，拆出类型、尺寸/重试常量和场景全景提示词。素材导入导出位于 `src/lib/material-transfer/`，拆出类型、错误、资源下载、ZIP 导入解析、Markdown、metadata 写回和 manifest 校验。官方 InstantMesh Gradio 由独立 FastAPI 项目 `tools/instantmesh-adapter` 适配为本地 REST API，NWT 只调用 adapter。

首页主体是左右结构工作台：左侧为图标 Logo、新消息、剧本入口、素材入口、消息搜索和按时间分组的会话列表，右侧为剧本选择、剧本管理、素材管理或 AI 聊天窗口。左侧支持收起；收起后不显示独立展开按钮，鼠标悬浮或键盘聚焦 Logo 时可展开。点击“新消息”回到剧本选择，剧本选择页默认展示我的剧本，使用每页 3 列 2 行的紧凑卡片，卡片点击即创建会话；超过 6 个剧本时才在卡片下方显示左右切换按钮和页数，不足一页或最后一页数量不足时卡片居中显示。点击“剧本”默认进入“我的剧本”，卡片会显示来源标记，右上角可查看社区剧本。社区剧本页沿用参考 GPT 探索页的剧本管理页，包含搜索、sticky 分类导航、按分类分区内容和剧本详情弹窗；分类高亮会通过滚动观察跟随当前内容变化。点击“素材”默认进入“我的素材”，素材管理页沿用相同的左侧入口和社区切换结构，但采用更偏图文画廊的卡片、固定内容风格分区和素材详情弹窗；卡片预览图点击进入详情，详情顶部设定板按 16:9 完整展示且不裁切，并支持点击放大查看；顶部风格包括写实、玄幻、科幻、悬疑、赛博、古风和末世，假面、地图、物品、生物、场景作为类型标签显示在卡片和详情里；其中“假面”只抽离人物外观、性格、说话方式和动作习惯，不包含背景故事、身世经历或世界关系。“操作”按钮会打开按内容宽度撑开的素材操作下拉，可导入 ZIP、导出全部自建素材并选择创建素材类型；选择假面会打开新建假面表单，桌面端表单左侧填写名称、内容风格、假面介绍、特征、身体信息、身体颜色配置、语音特征和性格特征；特征使用多行输入框记录标志动作、口头禅、表情习惯、视觉符号等外显内容；身体信息字段可直接输入，外观项通过自定义建议浮层辅助选择。右侧分为 AI 辅助对话和 16:9 横版角色设定板；AI 辅助调用默认 LLM 返回结构化 patch 并自动写入表单，设定板可本地上传预览或调用默认图片模型生成，生成按钮左侧提供真人拍摄、写实、二次元、厚涂、赛璐璐、国风、漫画、概念设定等绘制风格选择并写入生成提示词，保存时上传到 R2。选择生物会打开完整生物定义表单，左侧记录物种/族群的名称、内容风格、完整定义、分类生态、形态结构、颜色标记、发声与感知、能力限制和行为逻辑；右侧提供 AI 辅助和 16:9 生物设定板，AI patch 只允许写入生物 schema，设定板提示词包含主体生物、形态/解剖标注、比例参考、栖息地提示和行为逻辑小图示，保存时使用 `CREATURE` category、`kind: "creature"` metadata 与 `creature-boards` R2 路径。选择物品会打开物品表单，右侧提供设定板、单张模型输入图和 InstantMesh GLB；模型输入图写入 `modelInputImage`，生成模型只提交这一张图给 `/api/materials/item-model/stream`，旧 `viewImages` 只作为历史六视图展示和 ZIP 兼容字段。选择场景会打开紧凑场景表单，左侧填写场景名称、场景说明、内容风格、全景类型和区块，右侧 AI 辅助占满剩余高度；每个区块内可生成或上传六面体全景。场景全景默认按图片模型匹配调用预设：豆包/Seedream 与通用 OpenAI-compatible 服务直接请求 `4096x2048` 母图和 `4096x4096` 六面图，OpenAI 官方 `gpt-image-2` 使用 `3840x1920` 母图、`2880x2880` 六面图和 `quality: "high"`，其他 OpenAI 官方模型使用其支持尺寸后本地归一，Gemini 原生接口使用 `generateContent` 的画幅和清晰度选项；服务端最终按当前模型 sizeProfile 做母图切面、重绘归一、质检和后处理，已有旧尺寸素材继续兼容。场景全景生成走独立母图、母图首尾稳定、45 度水平偏移切六面、六面无遮罩并发参考重绘、失败 face 定向重试、像素级忠实升级提示词、固定高质量 WebP 输出以及相邻边和内侧条带质量质检的流程；生成链路不再设置额外图片请求超时，也不再为了压到 10MB 内循环降质量；最终六面来自 AI 重绘结果，但会用母图低频色彩约束整面色调，并对窄接缝带做轻量均衡。质检失败会定向重绘相关 face，最后一轮仍不达标时返回评分最好的六面结果并提示用户放大预览确认；若图片模型不支持参考图编辑，会提示切换支持图片编辑的模型，不再返回母图直切伪成功。生成阶段不上传 R2，保存场景时才分批上传母图和六面图并把 URL 写入 `SCENE` metadata；生成全景保存时不再按 10MB 拦截，手动上传的普通素材、参考图和全景图仍保留 10MB 校验；全景预览支持单击放大，预览会自动错峰加载 WebGL 全景而不依赖鼠标悬停触发；六面图放大层在存在母图时会以上下两层同时显示母图全景和六面图全景，两层各自支持拖拽视角与滚轮缩放；若图片已上传但 `SCENE` 素材记录写入失败，会尽力清理本次上传资源，并把迁移、存储或数据库失败原因映射成更具体的保存提示。保存假面会创建“我的素材”并写入 `StoryMaterial.metadata`，`previewUrl` 使用设定板 URL；保存生物会创建“我的素材”并写入完整物种 metadata，`previewUrl` 使用生物设定板 URL，详情按完整定义、形态结构、颜色标记、发声与感知、生态/能力和行为逻辑展示，滑块显示为文字档位；保存场景时 `previewUrl` 优先使用第一个区块的母图，没有母图时使用该区块前方面；场景详情头图同样只读取第一个区块，不扫描其他区块的第一张图片；假面详情会展开显示介绍、特征、身体信息和颜色色卡，语音与性格滑块会转换为文字档位说明而不是直接显示数值；新建和编辑假面、生物、物品、场景时都会带上“分享到社区”开关，但当前默认开启且锁定不可修改，详情页也只保留只读状态展示；编辑复用素材表单并更新同一条素材，导出会生成包含 `manifest.json`、`material.md` 和图片文件的 ZIP，生物素材会在 `material.md` 写入“生物数据 / Creature Data”，场景素材还会导出区块母图和六面图，导入 ZIP 会创建新的自建副本并默认保持社区可见，同时把包内图片重新上传到 R2，且会回写 `kind: "creature"` 的 `boardImage` URL，删除会永久移除素材主记录并由级联关系清理库条目；地图会打开可编辑表单与 Sigma 图谱画布，保存时同步 MySQL `StoryMaterial.metadata` 和 Neo4j 投影。社区素材支持加入我的素材，已加入状态会在卡片和详情里同步显示。聊天窗口采用居中消息流与底部多行输入框，输入框不显示剧本名称，并支持 `Enter` 发送、`Shift + Enter` 换行。会话页左上角统一显示当前剧本名称，点击后打开气泡操作列表，目前支持删除当前会话；右上角按上行/下行显示当前会话累计 AI token 消耗，服务商未返回 usage 时使用估算并标注。

- 地图会打开基础信息表单与 Sigma 图谱画布，画布会先等待容器尺寸稳定，只有在 WebGL 不可用或 Sigma 初始化失败时才回退到列表预览，保存时同步 MySQL `StoryMaterial.metadata` 和 Neo4j 投影。地图详情弹窗宽度与物品详情保持一致，避免单独撑得过宽。地图基础信息和图谱编辑都带右侧 AI 辅助，图谱编辑右下角提供返回基础信息的按钮。图谱编辑右上角提供格式化、拖动画布和节点/关系筛选工具；格式化使用 graphology ForceAtlas2 更新草稿坐标，筛选只影响当前画布可见内容，不写入素材。节点半径按当前可见关系数计算，节点 label 放在节点上方并绘制主题适配描边；未选中节点或关系时只显示关系线不显示关系标签，选中节点或关系时非关联关系降透明并隐藏非关联关系标签，关联节点与关系的 label 颜色按主题统一，深色模式下节点 hover 绘制使用自定义高对比 label，避免 Sigma 默认浅色标签底。图谱编辑中的“逐轮衍生”是草稿级 AI 操作，每轮使用当前整张图作为上下文，由 AI 自主判断延伸已有节点或开启新分支，只改当前编辑态节点和关系；每轮成功后会自动执行 ForceAtlas2 整理，衍生期间锁定拖拽、保存和手动编辑入口，仅保留停止衍生，保存图谱后才统一写入 MySQL 与 Neo4j。
- 地图图谱编辑右上角的最终图卡片走独立 `POST /api/materials/map-image/stream` 图像流式接口，不直接复用普通素材上传逻辑。服务端按节点关系把草稿拆成 1-100 节的迭代批次，第 2 轮起携带上一轮成功图、参考图片和接入说明生成世界地图插画；失败轮次会返回 `paused`，前端保留最后一张成功图并允许继续。最终图完成后，前端再把最终图片文件提交到 `POST /api/materials/map-image/outline`，服务端用 Sobel 边缘检测生成黑线白底 PNG 纯边框预览，仅用于当前编辑展示；随后再提交到 `POST /api/materials/map-geojson/generate`，服务端基于图谱布局与边框/最终图生成可保存的 GeoJSON，包含面、线、点和公里比例尺。手动上传最终图会写入 `StoryMaterial.previewUrl` 和 map metadata 的 `image` 字段，GeoJSON 写入 metadata 的 `geojson` 字段，但参考图片和边框图本身不会落库。
地图新建先保存基础信息，再进入全屏嵌入式 Sigma 图谱编辑区，编辑区直接占用弹窗剩余空间，左上角提供“新增节点”按钮，节点卡片中的“连线”操作会先选定源节点，再点击目标节点弹出关系弹窗，关系弹窗支持一键互换起点和终点，详情页只保留图谱编辑入口。
区块全景生成拆成母图和六面图两个 POST 流式接口。前端在收到母图后立即展示 2:1 全景预览，收到六面图后实时刷新缩略图和 Three.js cubemap；质检失败的 face 会进入“图片迭代中”状态，并按用户在生成按钮左侧设置的最多迭代轮次继续修复，默认 1 轮、上限 10 轮。服务端会先稳定母图左右环绕接缝，再以当前模型 sizeProfile 的尺寸切六面；`gpt-image-2` 档案为 `3840x1920` 母图和 `2880x2880` 六面图，其他默认全景档案仍为 `4096x2048` / `4096x4096`。母图稳定会先按 10% 环绕条带搜索低复杂度切口，将全景水平滚动到左右条带最接近的位置，再做窄带色彩与亮度稳定；六面 AI 高清化后会把靠边约 5% 的拼接保护区锚定回母图切面，降低相邻 face 的色差和结构漂移。迭代结束后以母图切面作为低频色彩权威，把最终六面图的高清亮度和纹理细节叠回母图色彩基准，并对窄接缝带做轻量均衡；色彩统一后会再次完整复检，若接缝综合指标变差则回退到统一前的最佳六面结果并提示用户放大预览确认。母图是区块级资产，可单独保存、写入 metadata，并随 ZIP 导出导入。

物品素材保存会在服务端区分 R2 上传失败、数据库或迁移失败、metadata 体积过大和普通持久化失败，并在前端映射为具体提示。若本次保存中新上传了设定板或模型输入图，但素材记录写入失败，服务端会尽力删除这些刚上传的 R2 对象，避免留下无归属资源。

物品素材的 AI 辅助和设定板生成支持两组独立的一次性参考图。前端只在弹窗内保存本地 `File` 预览，提交时分别通过 `assistHomeItemDraftWithImages` 和 `generateHomeItemBoardWithImages` 以 `FormData.referenceImages` 传给服务端；服务端按最多 3 张、单张 10MB、PNG/JPG/WebP 校验后，AI 辅助转为多模态 LLM 消息，设定板生成转为图片模型参考图参数。参考图成功使用后清空，不写入 `StoryMaterial.metadata`，也不参与 R2、ZIP 导入导出或 InstantMesh GLB 流程。

母图进入六面生成前会先经过 `analyzeScenePanoramaMotherImage` gate，指标包含左右 wrap 边缘色差、8%-12% 条带差、亮度差、地平线代理偏移和 seam 复杂度；阈值默认分别为 `18`、`28`、`18`、`6%` 和 `1.8`。母图 gate 失败会复用最多迭代轮次重试，仍失败时返回评分最高的母图并在流事件中标记 `qualityPassed=false`；六面接口会继续使用这张母图生成，但把母图质检结果带入完成事件，方便前端提示风险。接缝报告会输出 `color` 或 `geometry` issue，色差型优先走本地 seam/color 修复且不消耗 AI 重绘轮次，结构错位才按怀疑分选择 face 进入 AI 定向重绘。怀疑分综合 face 相对母图参考边的偏离、失败接缝数量和历史重试次数，每轮最多重绘 3 个 face。

剧本管理页不渲染右侧通用头部，避免与探索页自身导航重复；“我的剧本”右上角保留“+ 创建”占位按钮和“查看社区剧本”按钮，社区剧本页右上角显示“返回我的剧本”。搜索和分类栏在剧本页滚动容器内吸顶到最上方。点击剧本卡片打开详情弹窗，遮罩使用与其他弹窗一致的半透明背景和轻微模糊。当前版本暂不实现社区剧本加入操作，只在社区页对已加入我的剧本库的条目显示“已加入”状态。

首页右上角提供设置按钮。设置使用约为原宽度 2/3 的紧凑分栏弹窗：左侧为通用、账号、外观、AI 供应商、LLM 模型、向量模型、图片模型、关于等功能项；当当前登录账号匹配 `ADMIN_ACCOUNT` 时，额外显示“管理员”分类。通用页使用紧凑行式布局，展示语言切换、前往总站、打开文档、“显示思考内容”开关和退出登录；总站按钮会在新页面打开 `https://zrg.zrbyhelp.com/`，文档按钮会在新页面打开 `http://localhost:5173`，思考内容开关默认关闭，开启后会把供应商返回的 reasoning 内容展示给用户。账号页单独管理头像、显示名称和密码。头像和名称位于侧栏左下角，替代原数据库连接和默认 LLM 状态；头像从账号设置上传到 Cloudflare R2，支持 GIF/PNG/JPG/WebP，单个文件最大 5MB，前端会在提交前校验格式和大小。未配置公开域名时通过应用代理读取 R2 私有对象。显示名称修改后防抖自动保存；修改密码通过独立弹窗完成。排版密度会写入根字号、行高和密度变量，让 rem 尺寸的全局界面一起变化。AI 配置管理以扁平列表为主，新增或编辑时通过按钮打开弹窗填写，不常驻展示空表单，也避免大框套小框。管理员分类用于全局出站代理配置，支持启用开关、HTTP 代理、HTTPS 代理和 NO_PROXY；代理配置写入 `SystemSetting`，不使用环境变量作为入口。关于页签展示软件名称、作者、协议、联系方式、GitHub 仓库和 Star 请求，不展示后台入口。AI 配置直接落库并按当前登录账号隔离，供应商 API Key 只支持重填或清空，前端不返回明文；模型表单选择供应商后会通过服务端动作拉取 OpenAI-compatible `/models` 列表，再按 LLM、向量模型与图片模型场景做基础筛选。LLM、向量和图片模型列表行提供快捷默认图标，可直接把启用且供应商可用的模型设为默认。LLM 上下文窗口不作为用户配置项，避免和供应商模型默认上下文策略冲突。

## 管理员设置

项目不再提供独立 `/admin` 后台路由，原后台占位仪表盘和后台 shell 已移除。管理员身份只由当前登录账号是否等于 `ADMIN_ACCOUNT` 判断，不读取数据库 `role` 作为权限来源；`ADMIN_PASSWORD` 只用于确保该账号可登录。普通用户不会看到设置中的“管理员”分类，直接调用管理员服务端动作会返回 `FORBIDDEN`。

全局出站代理配置保存在 `SystemSetting.outboundProxy`。启用时必须至少填写一个 `http://` 或 `https://` 代理地址，默认 `NO_PROXY` 为 `127.0.0.1,localhost`，用于避开本地 MySQL、Redis、Qdrant、Ollama 等服务。服务端 AI 调用、图片生成、供应商 `/models` 拉取、素材导入导出的图片下载，以及 Cloudflare R2 读写都会读取这份全局配置。服务端会短暂探测已配置的代理端点并缓存健康状态；如果代理端口不可达，会回退为直连，避免地图衍生、AI 辅助和存储访问被本地代理拒绝连接阻断。

## AI 边界

Vercel AI SDK 仅负责前端流媒体对话展示。后端模型调用优先使用 `openai` SDK 或 LangChain 适配 OpenAI-compatible 服务；Gemini 原生图片模型使用 `generateContent` 图片接口。服务端出站请求会在每次调用前读取全局代理配置，`NO_PROXY` 命中的本地地址不走代理。LangGraph、LangChain 与 LangChain Splitter 负责工作流编排、链式处理和文本切分。场景全景的母图生成、六面切图、WebP 归一和接缝质检由 `sharp` 处理，本地六面体预览由 `three.js` 渲染；区块全景生成通过 `text/event-stream` 风格的服务端流把阶段状态和图片预览推给前端。

所有真实 AI 访问必须进入 Langfuse 观测。Next.js 服务端启动时通过 `src/instrumentation.ts` 注册 Langfuse OpenTelemetry 导出；OpenAI SDK 调用统一使用 `@langfuse/openai` 包装，LangChain 与 LangGraph 调用统一使用 `@langfuse/langchain` callback。图片生成保留总业务 span，并为场景母图、每个 face 生成、质检迭代和最终色彩统一写入子 observation，记录尺寸、face、轮次、最佳轮次、色彩指标和状态，不记录 base64 图片正文。非测试环境缺少 `LANGFUSE_PUBLIC_KEY` 或 `LANGFUSE_SECRET_KEY` 时，聊天回复、假面 AI 辅助、图片生成和供应商 `/models` 拉取都会直接报 `missing-langfuse-config`，不继续访问模型服务。

首页聊天回复通过本地 `POST /api/conversations/[conversationId]/stream` 接口返回 NDJSON 事件：`delta` 事件用于实时追加助手文本，`done` 事件返回已持久化的完整会话，前端再用数据库状态替换乐观消息。服务端调用默认 LLM 时会默认携带内部思考参数，并在系统提示中按用户偏好处理思考内容：默认要求模型不要输出私密推理；当用户开启“显示思考内容”后，若供应商在 `reasoning_content` 等字段返回 reasoning，流式与非流式回复都会把它标记为可见思考内容并保存到会话消息中。如果兼容供应商拒绝 `enable_thinking`、`reasoning_effort` 或 usage 流式参数，会自动重试为普通流式调用。

## 数据与任务

MySQL 由 Prisma 管理。首页工作台使用 `AppUser`、`AuthSession`、`StoryScript`、`StoryScriptLibraryEntry`、`StoryMaterial`、`StoryMaterialLibraryEntry`、`Conversation`、`ChatMessage` 持久化用户、会话 cookie、社区剧本目录、我的剧本库、社区素材目录、我的素材库、会话和消息；`SystemSetting` 保存全局 JSON 设置，目前用于出站代理配置。`AppUser` 保存账号、密码哈希、角色、显示名称、头像地址和 `showAiThinking` 偏好，思考内容默认关闭；管理员权限不读取 `role`，只按 `ADMIN_ACCOUNT` 对比当前账号。头像文件存储在 Cloudflare R2，数据库保存可访问 URL。假面设定板允许 PNG/JPG/WebP 且最大 10MB，Next Server Action 请求体上限设置为 80MB，给生成全景母图和六面图保存留出 multipart 余量；手动上传的普通素材仍保留 10MB 校验。使用 `AiProvider`、`LlmModel`、`VectorModel`、`ImageModel` 管理 OpenAI-compatible 供应商、聊天模型、向量模型和图片模型，其中 `AiProvider` 归属到具体 `AppUser`，模型通过供应商继承用户归属。当前版本开放账号密码注册，密码使用 `scrypt` 哈希，登录后写入 `httpOnly` 的 `nwt_session` cookie；`StoryScript` 作为社区目录，`StoryScriptLibraryEntry` 记录我的剧本来源，来源包括自己创建和社区添加。`StoryMaterial` 作为独立素材目录，`category` 保存素材类型，`style` 保存内容风格，`metadata` 保存假面等素材的结构化草稿并随工作台数据回传，`communityVisible` 控制素材是否出现在社区素材列表；`StoryMaterialLibraryEntry` 记录我的素材来源，来源同样包括自己创建和社区添加；编辑、导入、分享或删除自建素材都会校验当前用户的 `SELF_CREATED` 条目，当前版本分享状态默认写入并保持 `communityVisible=true`，前端开关锁定开启，后续功能解锁后再允许修改；删除自建素材会删除素材主记录并依赖 `onDelete: Cascade` 清理库条目；内置素材会在首页数据读取时自动确保存在并保持 `communityVisible=true`，默认示例会自动加入每个登录用户的素材库，`default-local` 仅用于未登录只读浏览兼容。AI 配置用户化迁移会把已有全局供应商和模型转移到账号 `q19946502`；如果该账号还没有密码，首次注册同名账号时会补写密码并保留迁移过来的配置。

素材导入导出使用 `jszip` 在服务端生成和解析 ZIP。导出只读取当前账号自建素材，并把 `manifest.json`、`material.md` 和真实图片打包；生物素材的 `material.md` 会输出“生物数据 / Creature Data”，导入时识别 `kind: "creature"` 的 `boardImage` 并回写新上传的 R2 URL。导入只信任 `manifest.json`，会创建新的自建素材副本，不覆盖现有素材；当前分享策略下导入副本同样默认社区可见。

Qdrant 用于向量检索，Neo4j 用于世界观图谱，BullMQ + Redis 用于 AI 分析、向量化、图谱构建等后台任务。

## 首页 AI 回复边界

首页发送消息后会调用当前会话所属用户默认启用的 LLM 模型生成回复。默认模型来自该账号设置弹窗中的 LLM 模型管理；如果当前账号没有启用的默认模型，聊天区会提示用户前往右上角“体验设置”配置 LLM，不再用 `.env` 回退模型代替用户配置。`.env` 中的 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL` 仅作为没有用户上下文的内部兜底配置。如果默认供应商缺少 API Key、密钥无法解密或模型调用失败，服务端会返回错误，不写入模拟助手消息。

前端发送消息时会先做乐观展示，并显示“正在思考并整理剧情”状态；收到流式 `delta` 后实时显示助手文本，服务端完成持久化后再使用最终会话与消息替换本地状态。前端时间统一使用相对与日期组合格式：60 分钟内显示“几分钟前”，今天显示 `HH:mm`，昨天显示“昨天 HH:mm”，更早显示日期和时间；英文界面使用英文等价文案。

向量模型和图片模型本次先完成配置、启停和默认项管理；后续 Qdrant 写入、LangChain Splitter 任务和语义检索会统一读取当前账号的默认向量模型，后续封面、场景图、角色图生成会读取当前账号的默认图片模型。
