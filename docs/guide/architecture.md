# 架构说明

## 前端

前端使用 Next.js App Router、React、TypeScript、Tailwind CSS 与 shadcn/ui 风格组件。语言路由始终带前缀：`/zh-CN` 与 `/en-US`。

首页右上角提供后台入口和语言切换下拉。语言切换保留当前路径结构，例如 `/zh-CN/admin` 切换为 `/en-US/admin`。

首页主体是左右结构工作台：左侧为图标 Logo、新消息、剧本入口、消息搜索和按时间分组的会话列表，右侧为剧本选择、只读剧本管理或 AI 聊天窗口。左侧支持收起；收起后不显示独立展开按钮，鼠标悬浮或键盘聚焦 Logo 时可展开。点击“新消息”回到剧本选择，剧本选择页使用每页 3 列 2 行的紧凑卡片，卡片点击即创建会话，左右按钮切换剧本组；点击“剧本”进入参考 GPT 探索页的剧本管理页，包含搜索、sticky 分类导航、按分类分区内容和剧本详情弹窗；分类高亮会通过滚动观察跟随当前内容变化。聊天窗口采用居中消息流与底部多行输入框，输入框不显示剧本名称，并支持 `Enter` 发送、`Shift + Enter` 换行。会话页左上角标题和副标题共同作为操作热区，点击后打开气泡操作列表，目前支持删除当前会话；右上角按上行/下行显示当前会话累计 AI token 消耗，服务商未返回 usage 时使用估算并标注。

剧本管理页不渲染右侧通用头部，避免与探索页自身导航重复；该页右上角保留“+ 创建”按钮，搜索和分类栏在剧本页滚动容器内吸顶到最上方。

首页右上角提供设置按钮。设置使用紧凑分栏弹窗：左侧为通用、外观、AI 供应商、LLM 模型、向量模型、关于等功能项，右侧展示语言切换、日夜模式、配色预设、排版密度、模型配置管理和项目关于信息，避免聊天顶部出现过多主操作。AI 配置管理以扁平列表为主，新增或编辑时通过按钮打开弹窗填写，不常驻展示空表单，也避免大框套小框。关于页签只展示软件名称、作者、协议、联系方式和 GitHub 仓库，不展示后台入口。AI 配置直接落库，供应商 API Key 只支持重填或清空，前端不返回明文。

## 后台框架

后台路由为 `/zh-CN/admin` 与 `/en-US/admin`。第一版后台暂不做鉴权，先提供运营核心框架：仪表盘、交互线程、世界图谱、任务队列、系统设置。

## AI 边界

Vercel AI SDK 仅负责前端流媒体对话展示。后端模型调用使用 `openai` SDK 或 LangChain 适配 OpenAI-compatible 服务。LangGraph、LangChain 与 LangChain Splitter 负责工作流编排、链式处理和文本切分。

## 数据与任务

MySQL 由 Prisma 管理。首页工作台使用 `StoryScript`、`Conversation`、`ChatMessage` 持久化剧本、会话和消息；使用 `AiProvider`、`LlmModel`、`VectorModel` 管理 OpenAI-compatible 供应商、聊天模型和向量模型。内置剧本包括基础 AI、世界观架构师、角色扮演导演、悬疑案件生成器、连载写作助手和设定研究员，由首页数据读取时自动确保存在。

Qdrant 用于向量检索，Neo4j 用于世界观图谱，BullMQ + Redis 用于 AI 分析、向量化、图谱构建等后台任务。

## 首页 AI 回复边界

首页发送消息后会调用默认启用的 LLM 模型生成回复。默认模型来自设置弹窗中的 LLM 模型管理；如果数据库中没有启用的默认模型，则兼容回退到 `.env` 中的 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、`OPENAI_MODEL`。如果默认供应商缺少 API Key、密钥无法解密或模型调用失败，服务端会返回错误，不写入模拟助手消息。

前端发送消息时会先做乐观展示，并显示“正在整理剧情”状态；服务端返回后再使用持久化后的会话与消息替换本地状态。前端时间统一使用相对与日期组合格式：60 分钟内显示“几分钟前”，今天显示 `HH:mm`，昨天显示“昨天 HH:mm”，更早显示日期和时间；英文界面使用英文等价文案。

向量模型本次先完成配置、启停和默认项管理；后续 Qdrant 写入、LangChain Splitter 任务和语义检索会统一读取默认向量模型。
