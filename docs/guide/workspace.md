# 首页工作台

首页是新世界小说的主要创作入口，采用左侧导航和右侧工作区结构。

## 左侧导航

- Logo：只保留图标，侧栏收起后可通过悬浮或键盘聚焦展开。
- 新消息：回到剧本选择，准备创建新的聊天会话。
- 剧本：打开剧本窗体，默认显示“我的剧本”。
- 素材：打开素材管理，默认显示“我的素材”。
- 搜索：按会话标题、剧本名和最近消息内容搜索。
- 账号区：左下角显示头像、名称和账号状态。

## 剧本库

剧本入口默认显示“我的剧本”。卡片会显示来源：

- `社区添加`：从社区目录加入个人库。
- `自己创建`：后续创建功能开放后由用户创建。

“社区剧本”保持探索页形态，支持搜索、分类吸顶、详情弹窗和开始聊天。当前版本只显示“已加入”状态，暂不提供加入写入操作。

## 素材库

素材入口与剧本入口并行，默认进入“我的素材”，右上角提供“创建”和“查看社区版本”。

- 素材顶部固定按内容风格分区：`写实`、`玄幻`、`科幻`、`悬疑`、`赛博`、`古风`、`末世`。
- 素材类型固定为 `假面`、`地图`、`物品`、`生物`、`场景`，显示在卡片和详情弹窗的标签上。
- `假面` 指人物外观、性格、说话方式、动作习惯等外在呈现，不包含人物背景故事、身世经历或世界关系。
- 素材卡片使用图文画廊形态，优先展示预览图或类型图标，再展示标题、来源、类型和简介。
- 素材卡片点击进入详情；详情顶部设定板按完整 16:9 比例展示，不裁切上下内容，点击详情中的预览图可放大查看。
- “操作”按钮会打开按内容宽度撑开的素材操作下拉，可导入 ZIP、导出全部自建素材，也可选择创建素材类型。选择 `假面` 会打开新建假面表单弹窗，可填写名称、内容风格、假面介绍、特征、身体信息、颜色配置、语音特征和性格特征。假面介绍只概述外观、性格、说话方式、动作习惯等外显特征；特征使用多行输入框记录标志动作、口头禅、表情习惯、视觉符号等可被看见、听见或互动感知到的内容；二者都不填写背景故事；身体信息中身高、体重可直接输入数值，其他外观项支持直接输入，并提供可点击展开、随输入筛选的建议浮层；语音特征使用连续滑块记录音高、语速、音量、语气起伏、情绪外显度、鼻音程度和气声比例；性格特征按基础人格、社交表现、情绪表现、关系表现、行为倾向分组记录 20 个 0-100 滑块。选择 `场景` 会打开紧凑场景表单，可填写场景名称、场景说明、内容风格、全景类型和多个区块；场景说明、区块名称、区块说明都不能为空。
- 假面弹窗右侧提供 AI 辅助和角色设定板。AI 辅助通过对话自动调整左侧表单，仍只处理外显内容；角色设定板为 16:9 横版，支持 PNG/JPG/WebP 且最大 10MB，可先本地上传预览或调用默认图片模型生成。生成设定板时会按图片模型预设请求尺寸，并在服务端归一为 `3840x2160` 的 4K 16:9 横版。图片生成前可选择绘制风格，例如真人拍摄、写实、二次元、厚涂、赛璐璐、国风、漫画和概念设定；保存假面时再上传到 R2。
- 场景弹窗右侧只保留 AI 辅助，并拉伸占满右侧剩余空间；区块全景生成放在每个区块卡片内部。区块全景默认按图片模型匹配调用预设：豆包/Seedream 与通用 OpenAI-compatible 服务直接请求 `4096x2048` 的 2:1 全景母图和 `4096x4096` 六面图，OpenAI 官方模型使用其支持尺寸后本地归一，Gemini 原生接口使用 `generateContent` 的画幅和清晰度选项；服务端会按 4K 尺寸切出前、后、左、右、上、下六面参考图并做后续归一，已有 1K 六面素材仍可继续预览、导入、导出和保存。切图会带 45 度水平偏移，避免母图左右 seam 落在后视角中心；随后并发进行 6 张无遮罩参考重绘。重绘提示词要求模型把参考图当作严格空间基准，只做像素级高清升级、细节恢复和材质增强，不改构图、机位、视场角、透视、裁切、物体位置、地平线或相邻边关系；每个 face 还会写入四条边对应的邻接关系，强调边缘必须清晰、连续、可拼接。任意 face 调用失败时只重试该 face，最多重试 2 次；重试提示会进一步降低创造性并要求更贴近参考图。六面每轮先做 sRGB/WebP 格式归一和相邻边、内侧条带质检，质检不通过时按失败接缝定向重绘相关 face；服务端会保留评分最好的轮次，后续轮次变差时不会覆盖最终结果。迭代结束后才基于母图切面做一次温和色彩统一，不再把母图切面或母图边缘混回最终结果。若图片模型不支持参考图编辑，会直接提示切换支持图片编辑的模型，不再降级为母图直切六面。全景类型复用假面设定板的真人拍摄、写实、二次元、厚涂、赛璐璐、国风、漫画和概念设定等选项，并写入生成提示词。全景预览区域支持单击放大，放大层内继续支持拖拽视角和滚轮缩放。
- 区块全景生成通过 `POST /api/materials/scene-panorama/stream` 流式返回进度、母图、六面图、质检、最终色彩统一和完成事件。生成按钮左侧可设置最多迭代轮次，默认 3 轮，范围为 1-6 轮；母图生成成功后立即显示为 2:1 预览且只保留在本次生成过程里，不上传 R2、不写入素材 metadata。六面图会在 AI 重绘成功后先显示并驱动全景预览，接缝质检不通过的 face 会显示“图片迭代中”，迭代结果返回后实时替换缩略图和 cubemap；最终仍只在收到完成事件后把最佳轮次且已统一色彩的六面图写入场景草稿，保存场景时才上传。
- 保存假面会创建一条 `MASK` 类型的“我的素材”，完整表单草稿写入素材 metadata，设定板 URL 写入 `previewUrl` 和 metadata；假面详情会把介绍、特征、身体信息、颜色色卡展开，并把语音和性格滑块转换为文字档位说明展示，避免直接显示难理解的数值。保存场景会在保存阶段才上传每个完整区块的六面图，生成阶段只保留本地预览；保存成功后只把六面图 URL 写入 `SCENE` metadata，`previewUrl` 使用第一个完整全景区块的前方面。若六面图已上传但素材记录写入失败，服务端和前端都会对本次上传图片做尽力清理，并向用户提示数据库迁移、连接或数据体积等更具体原因。自建素材默认不公开到社区，在详情中可通过“分享到社区”开关控制是否出现在社区素材列表，也可编辑或永久删除，编辑会复用同一表单并更新原素材，不创建副本；`地图`、`物品`、`生物` 创建入口仍只显示后续开放提示。
- 自建素材支持 ZIP 导入导出。导出全部只包含当前账号自己创建的素材，自建素材详情中还可导出单个素材；社区添加素材不显示导出入口。ZIP 内固定包含 `manifest.json`、每个素材的 `material.md` 格式化说明，以及 `images/` 下的 PNG/JPG/WebP 图片文件；场景素材还会在 `panorama/` 下导出区块六面图，并在导入时重新上传后回写 metadata。导入 ZIP 时不会覆盖现有素材，而是创建私密的自建副本，并把包内图片重新上传到 R2。
- “社区素材”支持搜索、风格吸顶导航、详情弹窗和“加入我的素材”。已加入的社区素材会显示“已加入”状态。

## 聊天

- 选择剧本后创建空会话，空会话只显示剧本欢迎语和输入框。
- 输入框支持 `Enter` 发送，`Shift + Enter` 换行。
- 发送后前端先乐观展示用户消息，再通过本地流式接口追加助手文本。
- 上方显示当前会话累计 token 用量，服务商未返回 usage 时使用估算。
- 会话标题区域可打开操作菜单，目前包含删除会话。

## 登录触发

以下行为需要登录：

- 创建会话
- 发送消息
- 删除会话
- 加入社区素材
- 进入或保存个人内容
- 管理 AI 配置
- 上传头像、修改密码和保存账号偏好

未登录触发这些操作时，会在当前页面弹出登录窗口。

## 设置

右上角“体验设置”包含：

- 通用：语言切换、前往总站、显示思考内容、退出登录。
- 账号：头像上传、显示名称、修改密码。头像支持 GIF/PNG/JPG/WebP，单个文件最大 5MB。
- 外观：亮度模式、配色预设、排版密度。
- AI 供应商：OpenAI-compatible 供应商管理。
- LLM 模型：聊天默认模型管理。
- 向量模型：检索和记忆相关模型管理。
- 图片模型：封面、场景图和角色图生成模型管理。
- 关于：软件信息、作者信息、仓库地址和 Star 请求。

发送聊天时，如果当前账号没有可用的默认 LLM 模型，或默认 LLM 的供应商缺少 API Key，聊天区会提示用户前往右上角“体验设置”补全对应配置。

“显示思考内容”默认关闭。开启后，如果供应商返回 `reasoning_content` 等 reasoning 字段，会在回复中展示。
