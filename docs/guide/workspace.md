# 首页工作台

首页是新世界小说的主要创作入口，采用左侧导航和右侧工作区结构。

## 左侧导航

- Logo：只保留图标，侧栏收起后可通过悬浮或键盘聚焦展开。
- 新消息：回到剧本选择，准备创建新的聊天会话。
- 剧本：打开剧本窗体，默认显示“我的剧本”。
- 素材：打开素材管理，默认显示“我的素材”。
- 搜索：按会话标题、剧本名和最近消息内容搜索。
- 账号区：左下角显示头像、名称和账号状态。

## 剧本库

剧本入口默认显示“我的剧本”。卡片会显示来源：

- `社区添加`：从社区目录加入个人库。
- `自己创建`：后续创建功能开放后由用户创建。

“社区剧本”保持探索页形态，支持搜索、分类吸顶、详情弹窗和开始聊天。当前版本只显示“已加入”状态，暂不提供加入写入操作。

## 素材库

素材入口与剧本入口并行，默认进入“我的素材”，右上角提供“创建”和“查看社区版本”。

- 素材顶部固定按内容风格分区：`写实`、`玄幻`、`科幻`、`悬疑`、`赛博`、`古风`、`末世`。
- 素材类型固定为 `假面`、`地图`、`物品`、`生物`、`场景`，显示在卡片和详情弹窗的标签上。
- `假面` 指人物外观、性格、说话方式、动作习惯等外在呈现，不包含人物背景故事、身世经历或世界关系。
- 素材卡片使用图文画廊形态，优先展示预览图或类型图标，再展示标题、来源、类型和简介。
- 素材卡片点击进入详情；详情顶部设定板按完整 16:9 比例展示，不裁切上下内容，点击详情中的预览图可放大查看。
- “操作”按钮会打开按内容宽度撑开的素材操作下拉，可导入 ZIP、导出全部自建素材，也可选择创建素材类型。选择 `假面` 会打开新建假面表单弹窗，可填写名称、内容风格、假面介绍、特征、身体信息、颜色配置、语音特征和性格特征。假面介绍只概述外观、性格、说话方式、动作习惯等外显特征；特征使用多行输入框记录标志动作、口头禅、表情习惯、视觉符号等可被看见、听见或互动感知到的内容；二者都不填写背景故事；身体信息中身高、体重可直接输入数值，其他外观项支持直接输入，并提供可点击展开、随输入筛选的建议浮层；语音特征使用连续滑块记录音高、语速、音量、语气起伏、情绪外显度、鼻音程度和气声比例；性格特征按基础人格、社交表现、情绪表现、关系表现、行为倾向分组记录 20 个 0-100 滑块。选择 `生物` 会打开新建生物表单，第一版定义物种/族群而不是单个个体，可填写名称、内容风格、完整定义说明、分类生态、形态结构、颜色标记、发声与感知、能力限制和行为逻辑；行为逻辑包含自由文本，并用攻击性、社交性、领地性、好奇心、警觉性、潜伏性、持续追踪、适应性、可驯化度、羁绊倾向、威胁反应、护食/护巢 12 个滑块记录互动倾向。选择 `场景` 会打开紧凑场景表单，可填写场景名称、场景说明、内容风格、全景类型和多个区块；每个区块可选择影视镜头规模预设：特写 2 米、近景 8 米、中景 25 米、远景 100 米、航拍 500 米；场景说明、区块名称、区块说明都不能为空。
- 假面弹窗右侧提供 AI 辅助和角色设定板。AI 辅助通过对话自动调整左侧表单，仍只处理外显内容；角色设定板为 16:9 横版，支持 PNG/JPG/WebP 且最大 10MB，可先本地上传预览或调用默认图片模型生成。生成设定板时会按图片模型预设请求尺寸，并在服务端归一为 `3840x2160` 的 4K 16:9 横版。图片生成前可选择绘制风格，例如真人拍摄、写实、二次元、厚涂、赛璐璐、国风、漫画和概念设定；保存假面时再上传到 R2。
- 生物弹窗右侧提供 AI 辅助和 16:9 生物设定板。AI 辅助返回严格 JSON `{ message, patch }`，只允许写入生物 schema 中的字段，可补全生态、能力、限制和行为逻辑，但不会把物种写成人类角色经历。生物设定板可本地上传或调用默认图片模型生成，提示词要求包含主体生物、形态/解剖标注、比例参考、栖息地提示和行为逻辑小图示；保存时设定板上传到 R2 的 `creature-boards` 路径，并写入 `CREATURE` metadata 的 `boardImage`。
- 物品弹窗右侧提供 AI 辅助、物品设定板、AI 模型输入图和 InstantMesh GLB。模型输入图只生成或上传 1 张图：纯白或浅中性纯色背景、完整物品居中、外轮廓保留安全边距、无文字标注、无多图拼版，由图片模型自动选择最能表达结构、轮廓、材质和功能的三分之四展示角度，不再固定 45 度，也不再生成前后左右上下六张图。生成时会要求模型只提取设定板中的主物品本体，忽略文字、比例尺、材质色块、小窗和二级视图，并保持关键部件数量、颜色分区、材质边界和可读厚度；物品设定板按虚构静态道具处理，不表现人物使用、真实伤害、血迹、威胁或攻击场景。保存物品时会写入 `modelInputImage`，旧 `viewImages` 只在历史素材详情和 ZIP 导入导出中保留；若 R2 上传、数据库连接、迁移或 metadata 体积导致保存失败，前端会显示对应原因，服务端会尽力清理本次保存中新上传的设定板和模型输入图。生成模型时前端只向 `/api/materials/item-model/stream` 提交 `modelInputImage`，服务端再调用 InstantMesh Adapter 生成 GLB。
- 物品 AI 辅助和物品设定板生成各有独立的一次性参考图区，可上传最多 3 张 PNG/JPG/WebP，单张最大 10MB。AI 辅助支持只上传参考图不输入文字，由默认 LLM 根据可见轮廓、部件、材质、颜色、用途和比例同步完善草稿；设定板生成会把参考图传给默认图片模型，用于约束物品轮廓、材质、比例和风格，但不保存参考图、不上传 R2、不写入素材 metadata。默认 LLM 需要支持图片输入，默认图片模型需要支持图片参考，否则会提示在体验设置中切换模型。
- 场景弹窗右侧只保留 AI 辅助，并拉伸占满右侧剩余空间；AI 辅助可单独上传最多 3 张 PNG/JPG/WebP 参考图，单张最大 10MB，支持只上传图片并让默认 LLM 读图同步完善场景草稿；如果默认 LLM 不支持图片输入，会明确提示切换支持读图的模型。区块全景生成放在每个区块卡片内部，每个区块还可临时上传最多 3 张母图参考图，只用于本次母图生成，不上传 R2、不写入素材 metadata。区块全景默认按图片模型匹配调用预设：豆包/Seedream 与通用 OpenAI-compatible 服务直接请求 `4096x2048` 的 2:1 全景母图和 `4096x4096` 六面图，OpenAI 官方 `gpt-image-2` 使用 `3840x1920` 母图、`2880x2880` 六面图和 `quality: "high"`，其他 OpenAI 官方模型使用其支持尺寸后本地归一，Gemini 原生接口使用 `generateContent` 的画幅和清晰度选项；服务端会按当前模型 sizeProfile 切出前、后、左、右、上、下六面参考图并做后续归一，已有 1K 六面素材仍可继续预览、导入、导出和保存。母图提示词要求左右 8% 可水平环绕，并预留低复杂度竖向切口；生成后会按 10% 环绕条带搜索最佳切口，把母图水平滚动到左右条带最接近的位置，再做首尾色彩和亮度稳定；切图会带 45 度水平偏移，避免母图左右 seam 落在后视角中心；随后并发进行 6 张无遮罩参考重绘。重绘提示词要求模型把参考图当作严格空间基准，只做像素级高清升级、细节恢复和材质增强，不改构图、机位、视场角、透视、裁切、物体位置、地平线或相邻边关系；每个 face 还会写入四条边对应的邻接关系，并把边缘 8% 作为拼接保护区。六面每轮先做 sRGB/WebP 格式归一和相邻边、内侧条带质检，并将靠边约 5% 的拼接带锚定回母图切面，质检不通过时按失败接缝定向重绘相关 face；服务端会保留评分最好的轮次，后续轮次变差时不会覆盖最终结果。迭代结束后会以母图切面作为低频色彩权威，把最终六面图的高清亮度和纹理细节叠回母图色彩基准，并对窄接缝带做轻量均衡；色彩统一后会再次复检，只有色差和接缝指标客观改善时才应用，否则回退到质检阶段的最佳六面图并提示用户预览确认色调。生成全景的 WebP 使用固定高质量配置，不再为了压到 10MB 内而循环降质量；保存生成全景时也不按 10MB 拦截，手动上传的普通素材、参考图和全景图仍保留 10MB 校验。若图片模型不支持参考图编辑，会直接提示切换支持图片编辑的模型，不再降级为母图直切六面。全景类型复用假面设定板的真人拍摄、写实、二次元、厚涂、赛璐璐、国风、漫画和概念设定等选项，并写入生成提示词。全景预览区域支持单击放大，预览会自动错峰加载 WebGL 全景而不依赖鼠标悬停触发；六面图放大层在存在母图时会分上下两层显示母图全景和六面图全景，两层各自支持拖拽视角与滚轮缩放。
- 区块全景生成分为母图和六面图两个流式接口：母图通过 `POST /api/materials/scene-panorama/mother/stream` 生成，六面图通过 `POST /api/materials/scene-panorama/stream` 以 `FormData` 提交场景草稿、区块、语言、迭代轮次和已有母图文件或母图 URL，并流式返回进度、六面图、质检、最终色彩统一和完成事件。生成按钮左侧可设置最多迭代轮次，默认 1 轮，范围为 1-10 轮；母图生成成功后立即显示为 2:1 全景预览，可单独保存。图片生成请求和生成图片 URL 拉取不再设置额外超时；单个 face 遇到上游超时、限流、网关或临时空结果时仍会先在服务端短重试，避免偶发模型错误直接中断整次生成；接缝质检不通过的 face 会显示“图片迭代中”，迭代结果返回后实时替换缩略图和 cubemap；最终只在收到完成事件后把最佳轮次的六面图写入场景草稿。
- 母图生成会复用同一个“最多迭代轮次”做独立质检与重试：服务端先稳定左右环绕，再检测左右边缘色差、8%-12% 条带色差、亮度差、地平线代理偏移和 seam 高复杂度风险；通过后正常提示成功。若所有轮次都未通过，单独母图接口仍会返回当前评分最高的母图并标记失败，前端保留这张母图供预览、保存和继续生成六面图。六面接缝质检会把问题分为色差型和结构错位型；色差型先做本地 seam/color 修复并复检，不占用 AI 重绘轮次，结构错位或本地修复仍失败时才进入 AI 定向重绘。失败 face 不再简单重绘接缝两侧，而是按相对母图边缘偏离、失败接缝数量和历史重试次数计算怀疑分，每轮最多重绘 3 个 face。
- 保存假面会创建一条 `MASK` 类型的“我的素材”，完整表单草稿写入素材 metadata，设定板 URL 写入 `previewUrl` 和 metadata；假面详情会把介绍、特征、身体信息、颜色色卡展开，并把语音和性格滑块转换为文字档位说明展示，避免直接显示难理解的数值。保存生物会创建 `CREATURE` 类型素材，metadata 固定 `kind: "creature"`、`version: 1`、`subject: "species"`，详情按完整定义、形态结构、颜色标记、发声与感知、生态/能力和行为逻辑展示，滑块同样转换为文字档位。保存场景会在保存阶段上传每个区块的母图和完整六面图；允许只保存母图，若存在任意六面图则必须补齐六面。保存成功后会把区块规模、母图 URL 和六面图 URL 写入 `SCENE` metadata，`previewUrl` 优先使用第一个区块的母图，没有母图时使用该区块前方面；场景详情头图同样只从第一个区块取图，不扫描其他区块的第一张图片。若图片已上传但素材记录写入失败，服务端和前端都会对本次上传图片做尽力清理，并向用户提示数据库迁移、连接或数据体积等更具体原因。自建素材当前默认公开到社区，但“分享到社区”开关仍处于锁定开启态，保存和详情只展示状态，不允许修改；`地图` 新建会先填基础信息再进入图谱编辑，节点坐标由系统自动生成，图谱编辑区直接占用弹窗剩余空间，左上角提供“新增节点”操作按钮，选中节点后可在节点卡片中点击“连线”选择下一个节点并打开关系弹窗，关系弹窗支持一键互换起点和终点，详情页保留只读预览，地图详情弹窗宽度与物品详情保持一致，画布会先等待容器尺寸稳定，只有在 WebGL 不可用或 Sigma 初始化失败时才回退到列表预览，关系列表、ZIP 导出 Markdown 的关系端点都会显示节点名称并附带节点 id，而不是只显示纯 id。保存时同时写入 `StoryMaterial.metadata` 和 Neo4j 投影。
- 地图基础信息弹窗和图谱编辑弹窗右侧都会显示 AI 辅助，对应草稿会直接写回同一份地图草稿；详情弹窗只保留图谱编辑入口，图谱编辑右下角提供“编辑基础信息”按钮用于返回基础信息面板。图谱编辑在至少 1 个节点时会显示“最多衍生轮次”和“开始/停止衍生”，每轮从当前节点中随机选 1 个种子节点调用 AI 生成新增节点和关系；衍生期间会锁定拖拽、保存、手动编辑入口和基础信息入口，仅保留停止衍生；衍生结果只保存在当前草稿里，用户点击“保存图谱”后才写入 MySQL 并同步 Neo4j。
- 自建素材支持 ZIP 导入导出。导出全部只包含当前账号自己创建的素材，自建素材详情中还可导出单个素材；社区添加素材不显示导出入口。ZIP 内固定包含 `manifest.json`、每个素材的 `material.md` 格式化说明，以及 `images/` 下的 PNG/JPG/WebP 图片文件；`material.md` 会为生物素材写入“生物数据 / Creature Data”章节。生物 ZIP 导入识别 `kind: "creature"` 的 `boardImage`，导入时会重新上传图片并把 metadata URL 回写为新的 R2 地址；场景素材还会在 `panorama/` 下导出区块母图和六面图，并在导入时重新上传后回写 metadata。导入 ZIP 时不会覆盖现有素材，而是创建新的自建副本，并按当前策略默认社区可见，同时把包内图片重新上传到 R2。
- “社区素材”支持搜索、风格吸顶导航、详情弹窗和“加入我的素材”。已加入的社区素材会显示“已加入”状态。

## 聊天

- 选择剧本后创建空会话，空会话只显示剧本欢迎语和输入框。
- 输入框支持 `Enter` 发送，`Shift + Enter` 换行。
- 发送后前端先乐观展示用户消息，再通过本地流式接口追加助手文本。
- 上方显示当前会话累计 token 用量，服务商未返回 usage 时使用估算。
- 会话标题区域可打开操作菜单，目前包含删除会话。

## 登录触发

以下行为需要登录：

- 创建会话
- 发送消息
- 删除会话
- 加入社区素材
- 进入或保存个人内容
- 管理 AI 配置
- 上传头像、修改密码和保存账号偏好

未登录触发这些操作时，会在当前页面弹出登录窗口。

## 设置

右上角“体验设置”包含：

- 通用：语言切换、前往总站、打开文档、显示思考内容、退出登录。文档按钮会在新页面打开 `http://localhost:5173`。
- 账号：头像上传、显示名称、修改密码。头像支持 GIF/PNG/JPG/WebP，单个文件最大 5MB。
- 管理员：仅 `ADMIN_ACCOUNT` 对应账号可见，用于保存全局出站代理配置；普通用户不会看到该分类。
- 外观：亮度模式、配色预设、排版密度。
- AI 供应商：OpenAI-compatible 供应商管理。
- LLM 模型：聊天默认模型管理。
- 向量模型：检索和记忆相关模型管理。
- 图片模型：封面、场景图和角色图生成模型管理。
- InstantMesh API：配置本地 InstantMesh Adapter，推荐 `http://localhost:3002`、API Key `local-dev`、提交路径 `/api/instantmesh/tasks`、状态路径 `/api/instantmesh/tasks/{taskId}`、超时 900 秒。
- 关于：软件信息、作者信息、仓库地址和 Star 请求。

发送聊天时，如果当前账号没有可用的默认 LLM 模型，或默认 LLM 的供应商缺少 API Key，聊天区会提示用户前往右上角“体验设置”补全对应配置。

“显示思考内容”默认关闭。开启后，如果供应商返回 `reasoning_content` 等 reasoning 字段，会在回复中展示。
