# 新世界小说

新世界小说是 AI 驱动的新体系交互式小说体验。它不是传统小说阅读器，阅读界面只是承载 AI 交互、剧情推进、世界观探索和内容生成的呈现方式。

## 快速入口

- 应用框架：Next.js App Router、React、TypeScript。
- 默认语言：中文 `zh-CN`，英文 `en-US` 为辅助语言。
- 包管理器：pnpm。
- 文档站点：VitePress。

## 首页工作台

首页是左右结构的 AI 聊天工作台：

- 左侧提供“新消息”、消息搜索和消息列表。消息列表按会话更新时间倒序展示，搜索会匹配会话标题、剧本名和最近消息内容。
- 左侧 Logo 只保留图标，提供“新消息”和“剧本”入口。侧栏收起后不显示独立展开按钮，鼠标悬浮或键盘聚焦 Logo 时可展开。
- 右侧是接近 ChatGPT 使用方式的 AI 聊天窗口：顶部显示当前会话，点击左上角会话标题与副标题区域可打开气泡操作列表，目前包含删除会话，后续可继续扩展更多会话操作；右上角按上行/下行显示当前会话累计 AI token 消耗，服务商未返回 usage 时使用估算并标注；消息流居中展示，底部是多行输入框。
- 没有消息时显示剧本选择；点击“新消息”也会先回到剧本选择。剧本选择页使用紧凑卡片分页展示，每页 3 列 2 行，卡片点击即创建会话，左右按钮切换剧本组。点击“剧本”进入参考 GPT 探索页的只读剧本管理页，提供搜索、sticky 分类导航、按分类分区内容和详情弹窗；分类高亮会跟随滚动内容变化。默认内置基础 AI、世界观、角色扮演、悬疑案件、连载写作、设定研究等剧本。
- 剧本管理页不显示聊天页通用头部，右上角保留“+ 创建”按钮；搜索和分类栏吸顶到剧本页内容区域最上方。
- 选择剧本后创建空会话。输入消息会立即乐观展示用户内容，服务端会调用设置中的默认 LLM 模型生成回复；如果未配置数据库默认模型，则回退到 `.env` 中的 `OPENAI_*` 配置。
- 输入框支持 `Enter` 发送、`Shift + Enter` 换行；输入框内不显示剧本名称，命令菜单快捷键不会在输入框中触发。
- 前端时间统一显示为 60 分钟内“几分钟前”，今天显示 `HH:mm`，昨天显示“昨天 HH:mm”，更早显示日期和时间；英文界面使用对应英文文案。
- 右上角提供设置按钮。设置使用紧凑分栏弹窗，左侧为功能项，右侧显示语言切换、日夜模式、配色预设、排版密度、AI 供应商管理、LLM 模型管理、向量模型管理和关于信息。AI 配置管理以扁平列表为主，新增或编辑时通过按钮打开弹窗填写，不常驻展示空表单，也避免大框套小框。关于页签展示软件名称、作者、协议、联系方式和 GitHub 仓库，不展示后台入口。AI 供应商 API Key 只支持重填或清空，不在界面展示明文。

## 常用命令

```bash
pnpm install
pnpm dev
pnpm test
pnpm lint
pnpm docs:dev
```

项目由用户自行运行，AI 不自动启动项目、服务或文档站点。
